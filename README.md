# Sharan Karuppannan — Research & Engineering Portfolio

[Visit the portfolio](https://trivik261.github.io/Portfolio_Website/)

A responsive, dependency-free portfolio featuring current research, public repositories, and the interactive GridWorld demo. Includes project filters, persistent dark/light themes, keyboard focus styles, and reduced-motion support.

## Run locally

From the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000. The current site uses `index.html`, the scripts/styles and workflow data in `assets/`, and the aquarium adaptation in `demos/`. No npm install or build is needed.

## Deployment

GitHub Pages serves the repository root on `main`. `.nojekyll` enables direct static publishing. The earlier Next.js source and exported bundles are retained for history; they are not used by the current homepage.

## Content accuracy

The 2025 paper is labeled an arXiv preprint. Only GridWorld is advertised as a live browser demo. Animated retinal workflows use DRIVE_AV reference annotations, not model predictions. CLAHE is applied to the sample green channel with clip limit 2 and an 8 × 8 tile grid. The vessel measurement is a minimum chord through a selected reference-mask pixel at preview resolution (4.5 px); it is not a clinical caliber estimate. GridWorld values and Durand–Kerner iterations are computed in the browser. Each tile supports pause/play and manual stage selection, respects reduced-motion preferences, and pauses offscreen. The portrait loads the current GitHub avatar. Company-confidential implementation details and unverified performance claims are omitted.

## Sample provenance

The fundus image and artery/vein labels are derived from `Dataset/DRIVE_AV/test/images/DRIVE0.png` and `Dataset/DRIVE_AV/test/label/DRIVE0.png` in [the public segmentation repository](https://github.com/trivik261/AVSegmentation-SWIN_ATT_WNET/tree/main/Dataset/DRIVE_AV/test). Masks are resized with nearest-neighbor interpolation. Red and blue labels are displayed as arteries and veins; green labels are preserved in the combined reference map.

## Public project scope

Nine independently owned project cards cover vision, learning, graphics, digital arithmetic, numerical computing, and networking. Forks, company-specific information, employment/academic CV details, resume downloads, and under-review manuscripts are excluded from the active page. The exploration history is ordered 2026, 2025, 2021, 2020. Geolocation source remains in its private repository; only a clearly labeled protocol illustration is public.

Pedestrian boxes were generated by the refreshed repository's OpenCV HOG entry point on its original public sample image. The tile uses those precomputed boxes and computes image-space geometry. The scheduler animation uses a trace exported from the tested standalone Python implementation. Aquarium is a Canvas adaptation of the native OpenGL concept. Verilog and networking tiles are workflow illustrations.
